## Circuit (E0-D6, brief K21)
| Ref | Part | Default | Why / source |
|---|---|---|---|
| J1 | JST BM05B-SRSS-TB (1.0 mm, top entry) | fitted | Cable JST A05SR05SR30K305B (order list), cut to ≥ 175 mm at the ReSpeaker end. **Pinout: 1 VDD, 2 GND, 3 CLK, 4 SEL, 5 DATA.** |
| D1–D3 | TI TPD1E05U06DYAR, SOD-523 | fitted | ESD on VDD, CLK, DATA at the connector (SLVSBO7O note: "as close to the connector as possible"). DYA (SOD-523, leaded) instead of the X1SON DPY for hand assembly (D42); 0.42 pF (DYA, datasheet table). MSL 3. |
| R1 | 100 Ω 0603 | fitted | VDD RC filter with C1: f_c = 159 Hz; drop 0.07 V at the mic's 670 µA. |
| C1, C2 | 10 µF 10 V X5R 0603, 100 nF 50 V X7R 0603 | fitted | Mic decoupling ≥ 100 nF + 10 µF (E0-D6). 0402 → 0603 (D42). |
| U1 | TI SN74LVC1G17DCKR, SC-70-5 | **fitted** | Schmitt buffer re-drives CLK next to the mic (E0-D6; bench 2.4 designed out). C3 100 nF at VCC. |
| R2 | 100 kΩ 0603 | fitted | Weak pull-down on the buffer input: the ReSpeaker may tri-state CLK when muted (inference, bench plan); TI requires defined inputs. |
| R3 | 0 Ω 0603 | **DNP** | Buffer bypass — fit only with U1 removed (bench 2.5 lever). |
| MK1 | MEMSensing MSM261DHP006 | fitted | PDM, VDD 1.6–3.6 V, 670 µA at 2.4 MHz, VIH 0.7 VDD, clock 1.1–4.8 MHz, edges ≤ 20 ns (DS-042 Ver.1.1). LCSC C22390138, shipped with the boards. |
| R4 | 33 Ω 0603 | fitted | DATA source termination at the mic (100 Ω alternative, bench 2.5 lever). |
| R5 | 0 Ω 0603 | fitted | **L/R from the cable SEL wire**, soldered to the vacated mic pad 5 on the ReSpeaker: each strip takes that position's original strap, so the channel order follows the U7 map without a jumper decision. |
| JP1 | 3-pad solder jumper | open | Local L/R strap (1–2 = GND, 2–3 = VDD) — only with R5 removed. |
| TP1–TP4 | SMD test pads | — | CLK and DATA at the mic, VDD, GND (bench 2.4/2.5, scope only if 2.5 fails). |

Cable termination at the ReSpeaker (bench plan "connect by function"): VDD → pad 1, CLK → pad 2, DATA → pad 3, GND → pad 4 (and 6), **SEL → pad 5**. The bench plan rev 3.5 still says "L/R does not go over the cable" — superseded by the brief's 5-way lead (CLK, DATA, 3.3 V, GND, select); SEL also sits between CLK and DATA as a static line.
