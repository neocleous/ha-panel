# HA panel — touch board rev D (decision 5A, 2026-11-07)

Replaces rev C (`hardware/rev-c`, unchanged) in the rev F chin seat: same 90 × 44 × 1.6 outline, R2 corners, no holes
except tented vias, flat front. Generated by `hardware/main-board/gen/touch_board.py` (schematic) and `pcb_touch.py`
(layout). KiCad 9.0.9. ERC 0 errors / 0 warnings; DRC (all severities, with schematic parity) 0 violations, 0 unconnected,
0 footprint errors (2026-11-09; `fix_touch_fpid.py` gave every footprint its library nickname, which cleared 12 parity
warnings the error-only DRC had not shown).

Layout: front copper = electrodes only. Back: U1, R1–R4, C1, C2, J1 pads, all traces (0.25 mm signal, 0.4 mm supply),
B.Cu track keep-outs behind the electrodes, electrode vias at each electrode's top edge (tented).

Assembly (one SMD side, the back): stencil or paste by hand, hotplate with the front face down on a clean sheet (the front
has no parts), then solder the HOST lead (iron). Bring-up: `i2cdetect -y 1` shows 0x1B.

Order options and limits: `../notes/jlc-fab.md`. **Paste:** the touch board's back pattern is on the combined stencil
