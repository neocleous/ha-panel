# Enclosure

`HA Panel Final.step` — full enclosure model (Shapr3D export, 2026-08-24).

Printed on Bambu Lab X1C, 0.4 mm nozzle, 0.2 mm layer height.
Touch-board pocket expects the rev-C PCB (100 x 44 x 1.6 mm, flat front
face, no mounting holes — adhesive/press fit). Clearances are sized for
FDM (0.2 mm); increase to 0.4–0.5 mm before ordering SLS/MJF, resin can
keep 0.2 mm (0.3 mm on long mating edges).

Related: PCB source, BOM and assembly docs in `hardware/rev-c/` on this
branch.
